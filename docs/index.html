🛡️ ChangeGuard

NLP-Based Context-Aware Semantic Change Detection and Impact Analysis System

📌 About the Project

ChangeGuard is a full-stack NLP application that compares two versions of a document. Instead of just highlighting word differences, it uses spaCy to understand the semantic meaning (Modality, Deadlines, Conditions, Negation, etc.) and generates a real-world impact explanation.

⚙️ Technologies Used

Python FastAPI spaCy scikit-learn NLTK TF-IDF SQLite HTML/CSS/JS

🧠 7 Semantic Change Categories

  • Modality Change: e.g., "may" becomes "must" (Permission → Obligation).
  • Deadline Change: e.g., "Friday" becomes "Monday".
  • Negation Change: e.g., "allowed" becomes "not allowed".
  • Condition Change: e.g., "above 75%" becomes "above 85%".
  • Restriction Change: e.g., "All students" becomes "Only final-year students".
  • Exception Change: e.g., Adding "unless they have a valid scholarship".
  • Object Change: e.g., "applications" becomes "certificates".
