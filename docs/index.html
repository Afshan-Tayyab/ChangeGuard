🛡️ ChangeGuard

NLP-Based Context-Aware Semantic Change Detection System

About the Project

ChangeGuard is a full-stack NLP application that compares two versions of a document. Unlike traditional word-diff tools, it uses spaCy to detect actual semantic meaning changes (like Modality, Deadlines, Negation, and Conditions) and explains their real-world impact.

Python FastAPI spaCy scikit-learn SQLite HTML/CSS/JS

⚠️ Live Demo Notice

Because this project uses a heavy Python NLP backend (spaCy, scikit-learn) and an SQLite database, it cannot be hosted on GitHub Pages (which only supports static HTML/JS).

To run the live interactive demo on your own computer, clone the repository and run:

cd backend
uvicorn server:app --reload
